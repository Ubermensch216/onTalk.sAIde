# Home 재설계: 친구·그룹별 업무 소통

2026-10-06, Asia/Seoul. 현재 개발 소스의 Home은 이 문서를 기준으로 한다. 기존 연락 준비 중심 설계를 대체한다.

## 사용자에게 주는 도움

Home은 “누구와 어떤 업무를 이야기했고, 다음 연락에서 무엇을 이어갈까?”에 답한다. 친구 목록은 온톡에서 관리하고 sAIde는 그 관계에 연결된 업무 맥락을 보여준다. 사람 찾기·조직 탐색·메시지 작성·업무 완료 처리·알림 설정은 기존 전용 화면을 사용한다.

## 정보 순서

| 영역 | 사용자가 확인하는 내용 | 다음 행동 |
|---|---|---|
| 그룹·친구·기간 | 어떤 관계와 자료를 보고 있는가 | 전체·그룹·한 친구 / 7일·30일·전체 선택 |
| 소통 통계 | 연결한 대화 원문·받은 쪽지·열린 업무 수 | 선택 범위 비교 |
| 이어서 확인할 업무 | 누가 연락했으며 어떤 업무가 남았는가 | 기존 업무 목록 확인 |
| 최근 대화 정리 | 지난 연락의 요약과 결정·질문·요청 후보 | 분석한 원문과 인용 근거 보기 |
| 받은 업무 연락 | 누가 무슨 업무로 쪽지를 보냈는가 | 요약·요청·기한·원문 확인 |
| 소통 흐름 | 최근 7일의 쪽지 보관·대화 관찰 흐름 | 날짜별 수 확인 |
| 친구별 소통 | 선택 범위에서 누구의 자료가 많은가 | 해당 친구로 필터 전환 |

360px 사이드카를 기준으로 세로 스크롤을 사용한다. 최신 대화 한 건과 업무 연락 두 건을 우선 표시하고 나머지는 펼쳐 본다. 필터는 온톡의 읽힌 선택 신호 또는 사이드카의 직접 선택으로 지정한다. 수동 선택이 온톡 친구 선택이나 그룹 편집을 바꾸지는 않는다.

## 자료 연결과 집계

- 친구의 표시 이름·직급·소속 해시로 연결을 유지한다. 화면 행 주소가 바뀌어도 유지하지만 고유 계정 ID로 인증한 연결은 아니다.
- 이름만 같은 쪽지는 확인 후보다. 사용자가 발신자·소속·원문을 비교하고 친구에게 연결한 후 집계한다. 다른 소속의 동명이인에게 자동 귀속하지 않는다.
- 쪽지 카드에는 보관된 AI 요약과 요청 후보를 사용한다. 분석이 없으면 원문 발췌로 명시한다.
- 대화창에서 선택한 원문을 분석하고 실제 상대를 선택해 Home에 연결한다. 선택 원문·AI 요약·검증된 인용 근거를 보관한다. 원문 선택을 바꾸면 이전 연결 제안을 비운다.
- 기간은 서울 날짜 기준이며 쪽지는 최초 보관일, 대화는 원문 관찰일을 사용한다. 온톡의 실제 송수신량 통계로 표현하지 않는다.
- 그룹에서 같은 쪽지나 친구가 겹치면 한 번 센다. 대화는 방 표시 힌트와 읽힌 메시지 키로 중복 선택 범위를 한 번 센다. 동일한 이름의 방·반복 문장에 대한 완전한 고유성은 보장하지 않는다.
- 열린 업무는 완료되지 않은 등록 업무 중 연결한 쪽지 또는 연결한 대화의 같은 방 힌트·메시지 키·본문에서 나온 것만 포함한다. 기간 밖의 오래된 업무도 표시한다. 미답변·상대방 처리 완료 여부는 추정하지 않는다.
- 접힌 그룹·화면 밖 친구를 전체 동기화한 것으로 표시하지 않는다. 그룹의 표시 인원과 읽힌 인원은 구분한다.

## 저장·수명

스키마 9에서 관찰한 최신 친구 스냅샷과 Home 대화 정리·친구 연결 테이블을 추가한다. 스키마 8 이하 저장소는 암호화 사본을 남긴 후 마이그레이션한다. 계정별 SQLCipher DB와 기존 암호화 백업·복구에 포함된다. 일반 대화 정리는 메모리에서 사용하고 Home 연결을 누른 선택 원문만 추가로 보관한다.

Home 대화 연결을 모두 해제하면 해당 Home 정리와 보관 원문을 삭제한다. 이미 업무로 등록한 원문은 기존 업무의 자료로 유지한다. 쪽지 연결을 해제해도 쪽지 사본은 기존 보관 자료로 남는다. 계정의 보관 자료 전체 삭제에는 Home 자료도 포함된다.

보이는 동안 10초마다 자료 변경을 확인하되 같은 자료이면 화면을 다시 만들지 않는다. 다른 문맥이나 계정으로 바뀌면 갱신을 멈추고 Home의 상세창도 닫는다.

## 확인한 범위

새 집계 테스트 6개를 포함해 292개 통과. 동명이인·중복 원문·서울 날짜 경계·기간 밖 열린 업무·대화 출처·계정 격리·재시작·연결 해제·스키마 8 마이그레이션·암호화 백업 복구를 검사했다.

합성 WPF 전체 70개 화면 중 Home은 전체·그룹·친구·빈 상태·480px 높이·125/150% 렌더를 포함한다. 대화 정리→친구 선택→Home 연결 및 선택 변경 후 연결 제안 만료도 검사한다. 이미지는 가상 자료이며 실제 온톡 사용자의 이력이 아니다. 새 Home의 실제 온톡 수용·키보드 사용성·실제 배율 도킹 검증은 남아 있다.
