# 사용자 매뉴얼 이미지 제작 기록

갱신: 2026-11-12. [사용자 매뉴얼](../README.md)의 이미지 출처와 개인정보 처리 기준이다.

## 새 Home 화면

`images/home-dashboard.png`는 `OnTalk.ContextPreview`가 가상 친구·쪽지·대화로 렌더링한 실제 WPF 패널이다. 온톡 창·사용자 이력·첨부의 직원 정보를 사용하지 않았으며 상태 표시에도 가상 자료임을 명시했다. 상단 '체크한 친구와 함께(단체 대화/단체 쪽지)' 빠른 실행 및 3개 카드(최근 쪽지·최근 대화·최근 업무)와 온톡 대화 목록에서 이름이 일치한 대화방(스키마 11 `HomeConversations`) 개편 화면을 반영했다. 이전 `friends-main.png`는 연락 준비 중심의 과거 Home 화면 기록으로 유지한다.

## 실제 메인 메뉴 화면

온톡 메인 창과 현재 메뉴에 맞춰 표시되는 실제 사이드카를 각각 Windows 창 캡처로 관찰했다. 안내 이미지에는 패널을 왼쪽, 온톡 메인 창을 오른쪽에 나란히 배치했다. 실제 화면에서는 공간에 따라 오른쪽 또는 왼쪽에 부착된다.

| 파일 | 화면 |
|---|---|
| images/friends-main.png | 친구 메인·과거 연락 준비 (기록용) |
| images/home-dashboard.png | Home 대시보드 (최신 그룹별 소통 정리) |
| images/organization-main.png | 조직도 메인·선택 직원에게 쪽지 (개편된 선택 목록과 발송 버튼) |
| images/conversations-main.png | 대화 목록·대화방 찾기 |
| images/notes-main.png | 받은 쪽지 목록·쪽지 메인 패널 (새 쪽지 단추, 검색·기간·첨부 필터, 보관 쪽지 카드 인라인 조회) |

사용자가 요구한 얼굴·이름·내용뿐 아니라 계정 ID·소속/직급·기관·개인 그룹명·대화방명·표시 참여자·메시지 미리보기·관찰 시각도 흐림 대상이다. 읽을 수 있어야 하는 일반 메뉴·탭·버튼·사용법은 보존한다.

원본 캡처를 임시 파일에 저장하는 요청은 자동 승인 검토에서 거부되어 진행하지 않았다. 대화에 표시된 캡처를 이미지 편집 도구에 참조해 강하게 흐림 처리한 결과만 저장소에 추가했다. AI 편집은 화면의 간격·크기·문구 재현에 차이를 만들 수 있으므로 안내용 이미지이며 정밀 UI 비교나 실제 입력 성공 증거로 사용하지 않는다. 원본 화면 파일·접근성 본문·계정 목록을 저장소에 넣지 않는다.

최종 PNG는 픽셀 데이터와 색 표현은 유지하고 생성 이력·텍스트·EXIF 등 부가 청크를 제거했다. 이미지 디코딩과 문서 링크 검사를 다시 통과했다.

실제 개인 쪽지를 추가로 열거나 대화 내용을 보관하는 대신 tools/OnTalk.ContextPreview의 가상 자료 WPF 캡처를 사용한다. 메인 화면과 함께 볼 수 있도록 개인정보 처리한 메인 이미지와 배치하거나 상세 화면 단위로 ‘합성 예시’로 표시한다.

실제 메인 화면과 합성 상세 패널을 함께 배치한 그림은 한 시점의 실제 부착 상태를 뜻하지 않는다. 미검증 대화 입력 반영 화면을 현재 제품 사용법의 예시로 넣지 않는다.

## 갱신 방법

1. 현재 소스의 빌드·파서 검증 결과와 기능 정책을 확인한다.
2. 메인 메뉴와 대응 패널을 각각 관찰한다. 입력·메시지 전송·삭제를 캡처 과정에서 실행하지 않는다.
3. 원본을 파일로 저장하지 않고 개인정보 처리한 결과만 docs/images에 추가한다.
4. 얼굴·문자·목록·그룹/방 이름과 계정 ID를 육안으로 재확인한다. 흐림이 부족하면 다시 처리한다.
5. 가상 자료 이미지는 합성 예시 표시를 유지한다. README 상대 이미지 링크와 배포 docs 복사를 확인한다.

캡처를 위해 임시로 작업 표시줄에 패널을 노출한 설정은 최종 소스와 실행 빌드에서 복원한다. 매뉴얼 갱신이 새 기능 구현이나 기존 ZIP 재배포를 뜻하지 않는다.
