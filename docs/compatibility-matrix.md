# 호환성과 기능별 지원 상태

갱신: 2026-10-17. 기존 실제 확인은 온톡 5.4.3(Electron 7.3.3/Chromium 78), Windows 11 Pro, 배율 100% 기준이며 새 Home과 조직도 개인화 작업은 합성 WPF·자동 시험으로 검증했다. 현재 배포 버전은 0.3.3이다. [사용법](../README.md), [실제 확인 기록](contextual-sidecar-phase4.md), [조직도 쪽지 안내](organization-personalized-notes.md)를 함께 읽는다.

‘실제 확인’은 해당 환경에서 제품 읽기/파서 또는 과거 쪽지 연동 결과를 관찰한 것, ‘자동 시험’은 단위/합성 WPF 시험, ‘미확인’은 실제 수용 검증을 완료하지 못한 것이다. 읽기 성공을 입력·전송 성공으로 일반화하지 않는다.

현재 설치·실행 버전은 **온톡 5.4.9**다. 2026-10-06 설치 파일의 FileVersion 5.4.9, 실행 프로세스의 ProductVersion 5.4.9.0을 확인했다. 실제 NoteWatcher→MSAA→파서로 열린 Home(친구)의 Main / Friends 문맥, 친구 17명·그룹 7개를 읽었다. 이는 현재 표시 목록의 관찰 수이며 전체/고유 개수 보장은 아니다. 2026-10-17 사용자 확인에 따라 코드의 확인된 버전에 5.4.9(5.4.9.0 포함)를 추가했다. 5.4.3도 계속 인정한다. 이 등록과 별개로 조직도·대화·쪽지 읽기/작성·예약·전송의 기능별 재검증 결과는 이 문서에 추가로 기록해야 한다.

| 기능 | 제공 상태 | 확인 범위와 제한 |
|---|---|---|
| 창 부착·문맥 전환 | 제공 | 친구·조직도·대화·쪽지 실제 패널 확인. 별도 창 부착·세션 정책 자동 시험 |
| 쪽지 메인 감지 | 제공·수정 | 실제 /notes와 Main / Notes 확인. 세 탭 fallback·숨김·충돌 자동 시험 |
| 받은 쪽지 읽기/보관 | 제공 | 과거 실제 읽기 확인. 열린 상세만, 보낸/보관 상세 미확인 |
| 요약·업무 후보 | 제공 | 로컬 AI/원문 근거 자동 시험, 소수 실제/합성 표본. 품질 보장 아님 |
| 업무·알림 | 제공 | 등록·출처·완료·기한·중복·격리 자동 시험. 실제 알림 확대 확인 필요 |
| 문자/뜻 검색 | 제공 | 문자 실제 확인 및 자동 시험. 뜻 검색 참고용, 대화 전체 색인 없음 |

| 그룹·자료 연결 | 제공 | 수신자 그룹·명시적 사람/쪽지 연결 자동 시험. 온톡 나의 그룹 변경 없음 |

## 검증·배포 기준

308개 테스트, 합성 WPF 72개, Release 오류·경고 0개. 4차 최초 276개, 후속 쪽지 수정 286개, Home 재설계 292개, 조직도 개인별 쪽지 및 Home 3카드 개편 308개 결과를 구분한다. README의 Home 이미지는 가상 자료의 실제 WPF 렌더이며 기존 온톡 이미지는 개인정보를 흐림 처리한 안내용이다. 실제 제품 수용 시험을 대신하지 않는다. 현재 소스의 배포 스크립트는 문서·이미지를 함께 복사하지만 기존 ZIP을 재생성하지 않았다.
