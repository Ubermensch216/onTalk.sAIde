# 호환성과 기능별 지원 상태

- 기준일: 2026-10-03
- 확인 환경: 온톡 5.4.3 (Electron 7.3.3), Windows 11 Pro, 화면 배율 100%, 모니터 2대, onTalk.sAIde 0.3.0
- 근거와 측정값은 [feasibility-results.md](feasibility-results.md)에 있다.

"확인"은 실제 온톡에서 동작을 본 것, "테스트"는 자동 테스트로만 본 것, "미확인"은 만들었지만 실제로 보지 못한 것이다.

위 환경과 아래 표는 기존 배포판의 기록이다. 2026-10-04 개발 소스의 메뉴별 실제 파서 확인·대화 입력 연동 한계·276개 테스트·60개 합성 화면 결과는 [4차 구현·검증 기록](contextual-sidecar-phase4.md)에 별도로 정리했다. 대화 입력 반영은 현재 제품 경로에서 확인되지 않아 제품 화면에 노출하지 않으며 초안 복사를 사용한다.

| 설계서 기능 | 상태 | 확인 수준 | 비고 |
|---|---|---|---|
| R01 로그인·연결 | 부분 지원 | 확인 | 계정은 온톡 저장 폴더로 추정하고 사용자가 한 번 확인한다. 로그아웃·계정 전환은 시험하지 못했다 |
| R02 쪽지 읽기 | 지원 | 확인 | 받은 쪽지만. 보낸·보관 쪽지 창은 미확인. 열어 본 쪽지만 수집한다 |
| R03 업무·알림 | 지원 | 테스트 | 등록·완료·알림 창은 화면에서 눌러 보지 않았다 |
| R04 통합검색 | 지원 | 확인 | 글자 검색 확인. 뜻 검색은 참고용 |
| R05 조직도·그룹 | 부분 지원 | 확인 | 고정 그룹만. 조건 그룹, 온톡 "나의 그룹" 반영은 없다 |
| R06 편집기 | 부분 지원 | 확인 | 일반 글자만. 서식은 다루지 않는다 |
| R07 발송 | 지원 | 확인(1건) | 즉시 전송 1건 확인. 실패할 때의 온톡 반응은 미확인 |
| R08 예약 | 부분 지원 | 확인 | 예약 시각 설정·취소 확인. 예약을 건 전송과 그 뒤는 미확인 |
| R09 첨부파일 | 부분 지원 | 테스트 | 사용자가 저장한 파일을 가져와 보관. 온톡 "저장" 자동화는 없다. PDF·HWP 내용 추출 없음 |
| R10 로컬 AI | 지원 | 확인 | 요약·후보·임베딩·초안. 쪽지 1건, 합성 표본으로만 평가 |

## 환경별

| 환경 | 상태 |

| 온톡 5.4.3 | 확인 |

| 온톡 싱글창 모드 | 미확인 |
